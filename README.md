# tarea-sem-09-AGi-grupo-2
tarea semana 09 de agentes inteligentes, hecho por el grupo 2 

Problemas de la tarea:
Actividad Práctica: Comparación de Modelos de Aprendizaje Automático
Objetivo
Desarrollar la capacidad de analizar y comparar diferentes algoritmos de aprendizaje automático 
aplicados a un mismo problema, evaluando su desempeño y justificando cuál resulta más adecuado 
para el conjunto de datos utilizado.
Instrucciones
Cada estudiante podrá utilizar el mismo notebook de Kaggle analizado en la actividad anterior o 
seleccionar uno nuevo.
Importante:
• Si utiliza el mismo notebook de la actividad anterior, deberá verificar que el autor no haya 
realizado ya una comparación entre varios modelos. En ese caso, deberá seleccionar 
algoritmos diferentes a los utilizados por el autor o elegir otro notebook.
Desarrollo
1. Descripción del Proyecto (2 puntos)
Responda brevemente:
• Nombre del notebook.
• Autor.
• Problema que busca resolver.
• Dataset utilizado.
• Algoritmo principal utilizado por el autor.
2. Reproducción del Resultado Original (3 puntos)
• Ejecute el notebook original.
• Registre la métrica principal utilizada por el autor (accuracy, F1-score, RMSE, etc.).
• Indique el valor obtenido.
